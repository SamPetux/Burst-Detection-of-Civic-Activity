# Хроника событий Нижнего Новгорода, 2026-06-01 .. 2026-11-15 (черновик)

Файл: `events_2026-06_11_draft.csv`, 96 событий. Статус: черновик ground truth, не полный.
Каталоги `results/` и `data/` не открывались (разметка слепая к детектору).

## Источники
- nn.ru: 80 событий (основной источник).
- opennov.ru: 16 событий (дополнение, в основном по районам и по ночным/вечерним сводкам).
- newsnn.ru (главная отдаёт ~13 КБ без ленты), pravda-nn.ru (sitemap-ы доступны, но свежие статьи в них не разобраны), vgoroden.ru (sitemap содержит только рубрики без дат статей): события из них не вносились.

## Как перечислялись статьи
1. nn.ru: `sitemap.xml` (gzip) -> `sitemaps/articles_2026_06 ... 2026_11.xml.gz`, всего 10 004 статей за период. URL содержит дату публикации (`/text/<рубрика>/YYYY/MM/DD/<id>/`).
2. Взяты рубрики `incidents`, `gorod`, `transport`, `ecology`, `house`, `realty`, `auto` (3 557 статей). Для каждой скачано начало страницы: заголовок и og:description.
3. Фильтр по заголовку/описанию: упоминание Нижнего Новгорода/области/районов + ключевые слова (ниже). Получено 610 кандидатов, после отсева объяснялок («Как...», «Когда...»), анонсов концертов и дублей осталось около 410.
4. Просмотрены заголовки кандидатов, вручную отобраны события, отобранные статьи открыты целиком: взяты datePublished (МСК), дата и время из текста, район только если он назван в статье.
5. opennov.ru: `sitemap-iblock-26*.xml` (3 865 URL с lastmod в периоде), отбор по слагу URL (названия районов, ключевые слова), отобранные статьи открыты.
6. Дубли слиты: одна строка на событие, `first_report_datetime` = самая ранняя из открытых публикаций.

## Ключевые слова
отключ*, без света/воды/тепла/газа, горячая вода, прорыв, порыв, затоп, пожар, взрыв, горит, возгорание, ураган, шквал, ливень, гроза, град, БПЛА, беспилот*, дрон, ракетная опасность, сирены, эвакуац*, коллапс, пробки, трамвай, метро, канатная, мост, массовое ДТП, перекрытие, снос, спил, КРТ, митинг, протест, жалобы, режим ЧС/повышенной готовности, сбой.

## Поля
- `start_time_msk` заполнено только если время названо в статье (12 из 96).
- `first_report_datetime` = datePublished статьи (МСК, +03:00).
- `confidence`: у всех high (статья открыта, дата точная); если дата начала выведена из текста («третьи сутки», «вечером 27 июля»), в сводке это указано; у событий без точной даты в тексте start_date = дата публикации.
- `district`: только если район назван в статье (или это Сормово/Автозавод/Канавино); иначе `unknown`; общегородское = `city`.
- Типы: fire_explosion, utility_outage, drone_air_raid, road_accident, transport_disruption, evacuation, district_emergency, storm, municipal_controversy, mass_event, road_closure, road_congestion.
- ID переназначены по порядку дат. Из 4 прежних событий подтверждены все (E001 - по nn.ru от 2026-06-02; 2026-07-02 - по nn.ru; канатная дорога 2026-07-05 - по nn.ru; атака 2026-11-01 - по nn.ru). Прежний источник по E001 (news.mail.ru) и прочие заменены на открытые статьи.

## Известные пробелы
- Цель 80-200 достигнута по нижней границе (96); покрытие по районам неравномерное: 62 события без района (в заголовках районы почти не указываются), moskovsky не представлен, nizhegorodsky/priokskiy по 1.
- Отбор вручную по заголовкам: пропущены события, чьи заголовки не содержат ключевых слов; рубрики `politics`, `economics`, `health`, `education`, `world` не просматривались.
- Не разобраны pravda-nn.ru, newsnn.ru, vgoroden.ru (нет доступной ленты по датам / не успели).
- Рядовые сводки «БПЛА сбиты над областью» без последствий, плановые перекрытия и единичные ДТП/пожары в области не вносились; воздушные тревоги включены только с видимыми последствиями для города.
- Часть событий вне границ города (Дзержинск, Кстово, Бор, Городец, Заволжье, Балахна) включена как влияющая на городские сообщества; район у них `unknown`.
- Время старта указано в 12 событиях; у остальных статья его не называет.
- События 2026-07-22 (ураган) и 2026-08-07 (шторм) имеют по несколько статей о последствиях (Бор без света 07-23); отдельными строками не разнесены.
- Каталожные даты opennov.ru в sitemap (lastmod) не равны дате публикации; датировка по открытым статьям.
